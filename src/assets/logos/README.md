# 구단 로고

여기에 `<슬러그>.png`(또는 `.svg`, `.webp`, `.jpg`) 파일을 넣으면 해당 구단의 도트 아이콘 대신 로고가 표시된다.
파일이 없는 구단은 기존 도트 아이콘을 그대로 쓴다. 정사각형 이미지를 권장한다. 넣은 이미지는 256×256 투명 배경 PNG로 맞춰 두는 것을 권장한다(가로로 긴 로고는 비율을 유지한 채 가운데에 놓는다). 2군·챌린저스 팀은 같은 슬러그의 1군 로고를 쓴다.

슬러그는 `src/data/teams.json`의 `slug`(2군은 `logo`)다. 리그가 달라도 같은 구단은 같은 슬러그(예: `t1`)를 쓴다.
