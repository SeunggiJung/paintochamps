# 구단 로고

여기에 `<슬러그>.png`(또는 `.svg`, `.webp`) 파일을 넣으면 해당 구단의 도트 아이콘 대신 로고가 표시된다.
파일이 없는 구단은 기존 도트 아이콘을 그대로 쓴다. 정사각형 이미지를 권장한다.

슬러그는 `src/data/teams.json`의 `orgSlugs`(프로 구단)와 `intlSlugs`(국제전 상대)에 구단 순서대로 적혀 있다.
예: `t1.png`, `geng.png`, `hle.png`, `kt.png`, `dk.png`, `drx.png`, `ns.png`, `bnk.png`, `brion.png`, `freecs.png`, `sandbox.png`, `griffin.png`
