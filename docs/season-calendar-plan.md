# 시즌 일정과 경기 중계 개편안 — 초안, 승인 대기

테스트 플레이 피드백:
- "프로 2부부터는 정해진 리그·대회 기간이 있어야 한다. 대회 중에도 턴이 끝난 뒤가 아니라, 리그와 대회가 끝나는 때 몇 위 했다고 바로 알려 주면 속도감이 좋겠다."
- "결승이나 중요한 경기는 kickru처럼 간단한 진행 애니메이션과 중계 멘트가 나오면 몰입이 좋겠다."

## 1. 지금 구조와 문제

- 한 시즌의 **모든 대회를 시즌 마지막 턴 뒤 결산 화면에서 한꺼번에** 치른다. 플레이어는 대회가 언제 열리는지 모르고, 결과는 숫자 한 줄로 끝난다.
- 대회 안의 경기 기록이 남지 않는다. (`runLeague`·`runElimination`은 최종 순서만 돌려준다.)
- 대회 중 능력치가 바뀌어도 시즌 마지막 능력치로 전부 계산된다.

## 2. 일정: 대회가 시즌 안의 정해진 시기에 끝난다

대회마다 **그 시즌의 몇 %가 지난 시점에 끝나는지**(`endsAt`, 0~1)를 `competitions.json`에 둔다. 모드의 턴 수와 무관하게 같은 달력이 되고, 대회는 `endsAt`이 속한 턴을 마칠 때(훈련 결과 팝업 다음, 이벤트 전) 그 자리에서 치른다.

| 단계 | 대회 (endsAt) | 표준(4턴) | 튜토리얼(2턴) | 정밀(12턴) |
|---|---|---|---|---|
| 프로 2부 | 봄 리그 (0.5) → 가을 리그 (1.0) | 2턴, 4턴 끝 | 1턴, 2턴 끝 | 6턴, 12턴 끝 |
| 프로 1부 AOS | 전반기 (0.25) → 선발전 (0.4) → 국제전 (0.5) → 후반기 (0.75) → 플레이오프 (0.9) → 월드 (1.0) | 1·2·2·3·4·4턴 끝 | 1·1·1턴, 2·2·2턴 끝 | 3·5·6·9·11·12턴 끝 |
| 프로 1부 FPS | 킥오프 (0.15) → 마스터즈 1 (0.3) → 스테이지 1 (0.5) → 플레이오프 (0.6) → 마스터즈 2 (0.7) → 스테이지 2 (0.9) → 플레이오프 (0.95) → 챔피언스 (1.0) | 같은 방식 | | |

- 같은 턴에 대회가 여러 개 끝나면 **순서대로** 하나씩 결과를 보여 준다.
- 방구석·지역 대회·아마추어 리그는 지금처럼 시즌 말에 치른다(2부부터 일정제). 필요하면 나중에 같은 방식으로 확장한다.
- **홈 화면에 일정 막대**를 둔다: 시즌 진행도, 지나간 대회(순위), 다음 대회와 남은 턴("전반기 리그 — 2턴 뒤").
- 승급·강등·엔딩 판정은 지금처럼 **시즌 결산**에서 한다. 결산 화면은 이미 본 대회 결과를 요약만 한다.

### 상태와 난수

- 시즌 중 치른 대회 결과를 `GameState.seasonRun`에 저장한다: 대회별 순위·상금·명성, 진출권(`qualified`), 챔피언십 포인트, 이후 대회가 참조하는 상위 팀 목록(`from`).
- 대회마다 난수를 `mixSeed(seed, 시즌, 대회 번호)`로 따로 만든다. 순서가 바뀌어도 같은 결과고, 저장 후 이어하기에도 같다.
- **대회 시점의 능력치**로 계산한다(지금은 시즌 마지막 값). 훈련이 대회 성적에 시기별로 반영된다.
- 세이브 마이그레이션: 진행 중인 시즌의 옛 세이브는 `seasonRun`이 없으므로 시즌 말에 한꺼번에 치르는 옛 방식으로 처리한다.

## 3. 결과 공개: 대회가 끝나면 바로 알려 준다

대회가 끝나는 턴에 팝업이 순서대로 뜬다.

1. 훈련 결과(기존)
2. **대회 결과 카드**: 대회 이름, 순위 / 참가 팀 수, 상금·명성, 진출 여부("플레이오프 진출", "월드 진출"). 1~3위는 메달 연출, 리그는 순위표 상위 5팀과 내 순위
3. 이벤트(기존)
4. 시즌 마지막 턴이면 시즌 결산

탈락했거나 진출하지 못한 이후 대회는 "이번엔 진출하지 못했다"로 건너뛴다.

## 4. 경기 중계: 중요한 경기는 진행과 멘트를 보여 준다

대상은 `big: true`인 대회(플레이오프·국제전·월드)의 **내 경기**와 결승이다. 리그전 경기는 순위표 요약만 보여 준다.

- 엔진이 대회를 치르면서 **내 경기 기록**(상대, 라운드 이름, 세트별 승패)을 남긴다. 결과를 미리 정하고 중계는 그걸 연출만 하므로, 같은 시드는 같은 중계가 나온다.
- 화면은 도트 장면 하나(내 팀 아이콘 vs 상대 팀 아이콘, 스코어보드)와 **중계 멘트 한 줄씩**으로 구성한다. 세트마다 1.2~1.8초 간격으로 스코어가 바뀌고, 어디를 눌러도 건너뛰어 결과로 넘어간다.
- 멘트는 `data/commentary.json` 템플릿에서 상황별로 고른다: 시작("결승, 양 팀이 입장합니다"), 앞서가는 중·따라잡는 중, 접전, 역전, 막판, 우승·준우승·탈락, 상대 팀 이름·세트 스코어 치환. 장르별 용어(FPS: 라운드, AOS: 한타·오브젝트)만 다르게 한다.
- 결승 우승은 지금의 폭죽 연출과 계약 연출처럼 도트 장면(트로피)으로 마무리한다.
- 중계 연출은 설정에서 끌 수 있다(빠른 진행). 정밀 모드는 기본 요약만.

## 5. 구현 단위 (승인 후)

1. `tournament.ts`: 내 경기 기록 반환(상대·라운드·세트 결과). 기존 최종 순서는 그대로.
2. `competitions.json`에 `endsAt`, `season.ts`를 "대회 하나 치르기"(`playEvent`) + "시즌 결산(이미 친 결과 요약 + 승강)"으로 분리. `GameState.seasonRun` 추가.
3. `applyTurn` 이후 `dueEvents(state)`로 이번 턴에 끝나는 대회를 알려 주고, 홈 화면이 결과 카드를 순서대로 연다.
4. 홈 화면 일정 막대, 결과 카드, 시즌 결산 요약 수정.
5. 봇이 새 흐름을 지나가도록 수정하고 난이도 리포트로 확인.
6. 중계: 경기 기록 → 멘트 선택(`commentary.ts`), 중계 화면과 도트 장면.
7. 기획서·CLAUDE.md·노션 갱신.

## 6. 위험과 확인할 것

- **밸런스 재측정이 필요하다.** 대회를 시점별 능력치로 계산하면 성장이 늦은 후반 대회가 약해지고, 시즌 초반 대회는 지금보다 불리하다. 상대 팀 강도 곡선(`tiers`)을 다시 볼 수 있다.
- 가장 큰 변경이다(시즌 결산 구조, 상태, 테스트 다수). 한 번에 하지 않고 1~4를 먼저 끝내고 직접 플레이로 확인한 뒤 6(중계)을 얹는 순서를 권한다.
- 튜토리얼은 2턴이라 한 턴에 대회가 3개씩 끝난다. 결과 카드를 하나로 묶어 보여 주는 안이 필요하다.
- 도트 장면(스코어보드·트로피)은 지금의 계약 연출처럼 코드로 그린다. 별도 에셋 제작은 없다.

## 7. 정해야 할 것

1. 프로 2부의 일정: 봄·가을 두 리그(승강은 가을 리그 순위)로 할지, 한 시즌 한 리그로 둘지.
2. 정규 리그 중간(턴마다)에 "현재 N승 N패, N위" 같은 중간 순위를 보여 줄지, 끝날 때만 보여 줄지.
3. 중계 대상: 플레이오프 이상의 내 경기 전부 / 결승만 / 월드만.
4. 구현 순서: 일정과 결과 공개(1~4)를 먼저 하고 중계는 그 뒤로 미루는 안(권장) / 한꺼번에.
