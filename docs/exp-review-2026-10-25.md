# 외부 플레이 리뷰(claude-exp.pdf) 정리 · 분류 · 우선순위 (2026-10-25)

사용자가 바탕화면에 둔 `claude-exp.pdf`(13쪽, "방구석 겜돌이에서 프로게이머되기 — 개선·강화 기획서", 2026-10-24 작성)를 읽고 정리한 문서다. 원본은 사이트를 직접 플레이한 Claude가 쓴 개선 기획서이고, 이 문서는 그 내용을 코드·`CLAUDE.md`와 대조해 **반응이 좋을 것 / 신중할 것 / 미룰 것**으로 나누고 우선순위를 정한 결과다. 구현 현황은 §5.

## 1. 원본 리뷰를 읽을 때 주의

- 근거는 튜토리얼 FPS 3시즌 + 같은 조건 15시즌 완주(가볍게 1판·투자하며 1판)뿐이다. 표준 모드·AOS·월드 우승·결승 중계·미니게임 재미는 직접 보지 못했다.
- 자동 클릭 환경에서 생긴 현상(확인창 중복, 말풍선이 미니게임을 가림)은 사람 플레이에서는 덜할 수 있다.
- 투자 효과(월드 결승 진출 vs 월드 진출 0회)는 각 한 판이라 크기를 단정할 수 없다.
- "가볍게 해서는 월드 우승이 안 보인다"는 `CLAUDE.md`의 난이도 방침(숙련 플레이가 20대 중반에 월드 제패)과 일치한다. **난이도를 낮추라는 신호로 읽지 않는다.** 길잡이 표시로 푼다.

## 2. 반응이 좋을 만한 것

| 항목 | 이유·메모 |
|---|---|
| 링크 미리보기(메타 태그·og 이미지) | 공유 때 썸네일이 없는 건 확인된 구멍. 작업 작음. **완료** |
| 엔딩 직후 후원 카드, 송금 링크·QR | 감정 정점에 후원 경로가 없었다. 카드 **완료**, 송금 링크·QR은 사용자 자료 대기 |
| 상위권 길잡이(결산에 다음 단계 조건·상위 팀 전력 대비 내 실력 격차) | "왜 월드에 못 가는지" 안 보임. 가장 설득력 있는 지적 |
| 리그 결과 이유(전력 비교·코치 한 줄) | 예상 4위가 6위로 끝나도 설명이 없다 |
| 도전 코드(같은 시드로 시작) | 친구 비교·스트리머 용도. 엔진이 이미 시드 기반이라 구현이 쉽다 |
| 이적 카드 추천/주의 태그, 국내 이적 확인창에 손익 요약 | 전력 −279·월급 −3,180만 같은 명백한 손해 카드가 섞인다 |
| 콜업 연속 거절 불이익 | 2부 잔류 파밍이 손해 없이 통한다 |
| 저장 코드 내보내기/불러오기 | 업데이트로 저장이 못 쓰게 된 전례가 있다 |
| 장비·레슨 효과 수치 표시 | 돈이 어디서 효과를 내는지 안 보인다 |

## 3. 하면 좋지만 신중해야 할 것

- **도감·업적 힌트·진행률**: `CLAUDE.md` §6의 "못 본 엔딩은 조건을 숨긴다(사용자 결정)"와 충돌할 수 있다. 상점에서 사는 **힌트 장(선택적 열기)** 으로 절충해 구현했다(§5). 진행률 막대·근접 알림은 아직.
- **컨디션 경고**: 경고 문구까지만. 사용자가 뺀 "예상 효과 미리보기"를 되살리지 않는다.
- **업적 상점 확대**: 능력치·판정을 직접 올리는 방향은 난이도를 무너뜨린다. 편의 위주(후보 재뽑기·시작 장비 Lv1·시작 특성 선택권)로만.
- **추천 훈련 균형 경고**: 경고 표시는 좋다. 추천 로직 자체를 바꾸면 봇 결과가 바뀌니 밸런스 리포트를 다시 돌린다(`BALANCE_RUNS=150`).
- **주간 챌린지·서버 순위**: 재방문에는 좋지만 "서버 없는 정적 웹"이 깨지고 개인정보 방침도 바뀐다. 1단계는 서버 없이 카드 공유.
- **초반 안전망**: 첫 대회 운이 5년을 가른다는 지적은 맞다. 다만 초반 사다리를 압축한 구조라 난이도 회귀 테스트에 영향이 크다.
- **경로 방식 주소·정적 소개/가이드 페이지**: 검색 유입에 필요하지만 해시 라우팅 구조를 바꾸는 큰 작업.

## 4. 별로이거나 지금은 미룰 것

- 영어 UI, 해외 후원 서비스(한국어 단일 서비스, 얻는 것 적음).
- 챌린지 모드·이벤트 체인·은퇴 후 에필로그(콘텐츠 비용이 크고 유입·완주율 데이터가 아직 없다).
- 후원 혜택 B(닉네임 감사 명단): 개인정보 처리·약관 7조 수정이 따른다. 원본도 마지막으로 미루라고 했다.
- 후반 경제 대재설계: 돈이 남는 건 투자 안 한 플레이에 한정(투자한 판 최종 자산 4.6억). 먼저 효과 수치 표시로 정보 문제를 풀고 그 뒤에 판단.
- 볼륨 슬라이더·버튼 이름(접근성): 맞는 지적이지만 낮은 우선순위.

## 5. 우선순위와 구현 현황

**P0 (2026-10-25 완료, 커밋 `7430fc4`·`b90c485`·`d3351b1`·`38eef2f`)**
1. ✅ `index.html` 메타 태그(description·og·twitter·canonical), `public/robots.txt`·`sitemap.xml`, `public/og.png`(1200×630, 우승 장면).
2. ✅ 첫 방문엔 업데이트 로그 팝업을 띄우지 않는다. 이전 방문 기록(`paintochamps:updatelog:seen`)이 있고 새 업데이트가 있을 때만 뜬다. 오늘 하루 안 보기 등으로 건너뛰면 타이틀 '업데이트' 버튼에 `N` 배지(`updateLog.ts` `hasUnseenUpdate`).
3. ✅ 엔딩 화면 아래 후원 카드(`support.ts` `endingSupportCard`, 문구는 `support.json` `endingMessage`, '다시 보지 않기'는 `paintochamps:support:ending-hide`). ⬜ 송금 링크·QR 미구현.
4. ✅ 서비스 소개의 엔딩 수를 `ENDINGS.length`로 자동 표기(11종 → 12종).
5. ✅ 확인 팝업 중복 방지(`confirm.ts`: 이미 떠 있으면 겹친 호출은 **끝나지 않는 Promise**를 돌려준다 — 취소로 처리하면 구단 인수 흐름이 취소 쪽으로 넘어가기 때문), 엔딩 진입 때 남은 팝업 정리(`dismissAllSheets`).
6. ✅ (추가 요청) 업적 상점에 **엔딩 힌트·업적 힌트**(토큰 3개, 최대 5장). 도감에서 못 본 항목을 눌러 한 장 쓰면 그 항목의 달성 조건(`desc`)이 열리고 `MetaSave.hints`에 저장된다.

## 6. 원본이 지적한 위험·결정 사항

- **실존 구단명·로고 + 후원**: 가장 큰 리스크로 꼽혔다. 홍보를 넓히기 전에 선택지를 정하라고 했다(1 현행 유지 / 2 로고만 제거 / 3 가상 구단·리그). 사용자가 2026-10-20에 실존 이름을 쓰기로 정했으므로(§3-4 `CLAUDE.md`) 후원·홍보 확대 시점에 다시 판단할지 사용자가 정한다. 법률 자문이 아니다.
- **개인 계좌번호·개인 GitHub 주소가 화면에 그대로 공개**: 후원 전용 계좌·링크로 분리 권고.
- **사업자·소득 신고, 게임물 등급, 청소년 연령 안내**: 원본도 확인하지 못했다. 필요하면 사용자가 직접 알아본다.
- **저장 데이터 호환**: 규칙이 바뀔 때 `saveVersion` 마이그레이션과 사전 공지.
- 분석 도구·후원 혜택·문의 채널을 바꾸면 개인정보처리방침·이용약관을 같은 날짜로 함께 고친다.
- 로드맵 속도(8일에 업데이트 8건)는 1인 개발에서 오래 못 간다. 단계 안의 항목을 줄이는 쪽으로 조정.
