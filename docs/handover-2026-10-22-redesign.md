# 인수인계: UI 리디자인 브레인스토밍 (2026-10-22)

새 세션이 가장 먼저 읽을 것은 `CLAUDE.md`이고, 그다음 이 문서다. 어제 문서(`docs/handover-2026-10-21.md`)는 구단 시장·경력·업적 상점 작업, 이 문서는 **그 뒤에 시작한 UI 리디자인 브레인스토밍**을 다룬다.

## 1. 지금 어디까지 왔나

- **코드는 한 줄도 바꾸지 않았다.** 리디자인은 아직 **설계 단계(브레인스토밍)** 이고, `superpowers:brainstorming` 스킬의 HARD-GATE(설계 문서 승인 전에는 제품 코드를 만들지 않는다)가 걸려 있다.
- 지금까지 한 일은 ①현재 화면 기준선 촬영 ②킥루(레퍼런스) 조사 ③사용자와 방향 결정 ④결정 사항을 시안(HTML)으로 확인, 이 네 가지다.
- **설계 문서 작성 완료·승인(2026-10-22): `docs/superpowers/specs/2026-10-22-ui-redesign-design.md`.** 사용자가 §8 질문에 답하며 구현으로 넘어가자고 했다: ①**브랜치 없이 `master`에서 작업**(단 push는 사용자가 요청할 때만), ②**구현은 한 번에 이어서**, ③**CellCog 이미지는 타이틀 4장 외에는 더 만들지 않는다(크레딧 사유)**. 다음 단계는 `superpowers:writing-plans`로 구현 계획을 쓰는 것이다. 이미지 원본 PNG 5장(약 17MB)은 저장소 용량 때문에 커밋하지 않고 로컬에만 둔다(게임에 넣을 줄인 WebP는 구현 때 `src/assets`에 추가).
- 다음에 할 일은 §5 참고(§5의 "아직 안 정한 것"은 대부분 정해졌고, 남은 건 위 설계 문서 승인).

## 5. 다음에 할 일 (브레인스토밍 절차 이어서)

`superpowers:brainstorming` 스킬은 "질문 한 번에 하나, 이해한 부분은 200~300자로 돌려주기, 시안은 보여 주기" 방식이다. 이미 시안 서버를 써도 된다고 사용자가 허락했다.

## 6. 일정 추정 (사용자에게 말한 것)

테마 3개 포함 전 화면 리디자인은 **약 7~10 작업일**(하루 4~6시간 기준)로 말했다. 준비 0.5 + 토대(토큰·공통 컴포넌트) 1~1.5 + 핵심 화면 2~3 + 나머지 화면 2~3 + 마감 1. 테마를 3개로 늘려서 하나만 만들 때보다 1~1.5일이 늘었다. 확인 횟수와 방향 변경이 일정을 가장 크게 흔든다.

## 9. 사용자 스타일 메모

- 한국어, 결과는 요약해서 말해 달라는 편이고 "이번 턴에 한 작업" 요약을 매 응답 끝에 붙인다(`CLAUDE.md` §9).
- **시안으로 보여 주는 방식을 매우 좋아한다**("와씨 개좋은데?"). 말로 설명하기보다 시안을 먼저 보여 주고, 둘 이상을 비교할 때는 나란히 놓고, 결과는 직접 열어 눈으로 확인한 뒤 말한다.
- 레퍼런스(킥루)를 정확히 베끼기보다 "참고해서 더 다듬고 꾸미라"는 방향이고, 선택지를 하나로 좁히기보다 **여러 개를 설정으로 고를 수 있게** 하는 걸 선호한다(테마·글자·움직임).
- 솔직한 한계 설명을 허용하고 오히려 정확한 설명을 원한다(도트 그림 수준 질문에 한계를 말했을 때 좋은 반응).
- **시안으로 보여 주고 사용자가 정한 것은 그 즉시 이 인수인계 문서에 기록한다**(2026-10-22 사용자 지시: "어떻게 하기로 결정한 거는 무조건 바로 인수인계에다가 넣어놔"). 다음 질문이나 시안으로 넘어가기 전에 먼저 기록한다.
- **시킨 것만 한다.** 2026-10-22에 "사람이 부자연스럽다"를 얼굴·그림체 전면 재작업으로 넘겨짚고, 시키지 않은 타이틀 장면 교체·업데이트 로그 수정·커밋 시도까지 해서 크게 혼났다(작업은 전부 롤백했다). 모호하면 추측으로 실행하지 말고 먼저 되물을 것. 지적이 "손이 키보드에서 떨어져 있다"처럼 구체적이면 **그 점만** 고친다. 한 번에 하나씩 차근차근.
- UI 전체 개편 중에는 **코드(`src/`)를 건드리지 않는다**(설계 승인 전 HARD-GATE). 시안은 `docs/redesign-mockups/`의 독립 HTML로만 만든다. 화면 확인은 Playwright 브라우저로 직접 열어 캡처·클릭해 본 뒤 보여 주고, 사용자 확인용으로 Edge에서도 연다(`Start-Process msedge`).
- 이름 취향: 돈을 쓰는 화면 이름은 '돈 쓰기'보다 **'지출 계획'**.
