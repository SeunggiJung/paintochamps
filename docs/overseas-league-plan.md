# 해외 리그·해외 이적 기획서 (초안, 2026-10-20)

피드백 8번("해외 리그 이적, 리그 자체의 순위 집계, 이적 제안에 리그 순위·팀 순위 표시")과 업적 "도서관장"(외국 개최 월드 우승)을 한 번에 풀기 위한 기획이다. **범위는 프로 1부로만 한정한다**(사용자 결정). 수치는 모두 초안이고, 기능 구현 전에 §9의 결정이 필요하다.

## 1. 한 줄 목표

"국내 1부에서 성공한 선수가 더 큰 무대·더 높은 연봉을 위해 해외 리그로 건너가 **적응이라는 대가를 치르고**, 월드에서 국가별 자존심 대결까지 가는" 후반부 커리어 축을 만든다.

## 2. 범위

| 포함 | 제외(이번에 안 한다) |
|---|---|
| 해외 **1부** 리그 데이터·일정·팀 강도·월급 | 해외 2부·아카데미, 해외 아마추어 |
| 국내 1부 → 해외 1부 이적, 해외 → 해외·국내 복귀 | 국가대표·국제 친선전(피드백 14번, 별도 설계) |
| 해외 생활의 대가: **적응도**, 해외 이벤트, 언어 코치 시설 | 외국인 선수 쿼터·비자 같은 제도 |
| 리그 순위 집계(국제전 성적 기반)와 제안 카드 표시 | 선수 개인의 국적 설정 |
| 월드 개최지 로테이션, 도서관장·해외 업적 | 계약 기간·재계약(5·6번 후속과 함께) |

## 3. 지금 구조 (기획의 출발점, 코드로 확인함)

- 팀 풀은 `data/teams.json` `leagues`의 장르군(`aos`=AOS·RTS, `fps`=FPS·격투)별로 `pro1`·`pro2`·`intl`로 나뉜다. AOS `pro1`은 LCK 10팀, FPS `pro1`은 VCT 퍼시픽 12팀이고, **해외 팀은 `intl` 24팀(AOS: LPL·LEC·LCS·LCP·CBLOL, FPS: 아메리카·EMEA·중국)에 이름만 있고 리그 정보가 없다.**
- `intl` 팀은 MSI·월드·마스터즈 같은 국제전 상대로만 나온다. 전력은 리그 구분 없이 `tiers.intl`(평균 770, 편차 35) 하나다.
- 1부 시즌 일정(`competitions.json` `pro1.aos|fps`)은 장르군마다 하나이고 이름에 LCK·VCT 퍼시픽이 박혀 있다.
- 이적은 항상 **같은 1부 풀**의 팀 3곳이다(`pickTeams(…, 'pro1', …)`, 시즌 결산·시즌 중간 제안·이적 요청 모두 동일). 플레이어의 "소속 리그"라는 개념은 없고 `TeamRef`는 `{id, name}`뿐이다.
- 돈 규모는 소속 **단계**(`moneyScale`)를 따르고, 월급은 단계별 기본값 × 팀 강도 × 명성 보너스다(`salaryOf`).

→ **가장 큰 구조 변화는 "소속 리그"를 상태에 넣고, 일정·상대·월급·국제전 풀을 리그 기준으로 바꾸는 것**이다.

## 4. 리그 모델

### 4-1. 데이터 (`data/leagues.json` 신설, `teams.json` 정리)

리그마다 한 항목:

```
{ "id": "lpl", "family": "aos", "name": "LPL", "region": "중국", "home": true|false,
  "strength": 20,        // 팀 전력에 더하는 리그 보정 (국내 LCK = 0 기준)
  "salaryMult": 1.4,     // 월급 배율
  "prestige": 1.0,       // 대회 명성 보상 배율
  "transferable": true,  // 이적 제안이 오는 리그인가 (false면 국제전 상대로만 나옴)
  "size": 8 }            // 1부 팀 수
```

- `teams.json`의 `intl` 24팀을 **리그별 `pro1` 목록으로 옮긴다**(팀 id는 기존 규칙 `<aos|fps>_pro1_<slug>` 유지, 리그는 `league` 필드로 구분). 옛 세이브의 `intl` 팀 id는 마이그레이션에서 새 id로 매핑한다.
- 1부 리그 구성(초안):

| 장르군 | 국내 | 이적 가능 해외(추천 3개) | 국제전 전용 |
|---|---|---|---|
| AOS·RTS | LCK(10팀) | LPL, LEC, LCS | LCP, CBLOL |
| FPS·격투 | VCT 퍼시픽(12팀) | VCT 아메리카스, VCT EMEA, VCT 차이나 | — |

- 지금 `intl` 24팀을 리그별로 나누면 리그당 4~6팀뿐이라 **리그전·플레이오프를 돌리려면 팀 보강이 필요**하다(§9 결정 5). 해외 리그는 8팀(LPL은 10팀)을 목표로 한다.
- **국제전 풀은 "내 소속 리그를 뺀 모든 리그의 1부 팀"으로 바뀐다.** 그래서 LPL로 이적하면 LCK 팀이 MSI·월드 상대로 나타난다. 국제전 상대 전력은 팀의 리그 `strength`를 반영한 값으로 정한다(지금처럼 평균 770 근처를 유지해 난이도 회귀를 지킨다).

### 4-2. 리그 강도와 보상 (이적의 득실을 만드는 장치)

이적이 항상 이득이 되면 선택이 아니라 정답이 된다. 리그마다 **득과 실이 섞이게** 한다(초안 수치):

| 리그(AOS 예) | strength | 월급 배율 | 명성 배율 | 성격 |
|---|---|---|---|---|
| LCK | 0 | 1.0 | 1.0 | 기준. 경쟁이 치열 |
| LPL | +20 | 1.5 | 1.0 | 연봉이 가장 높고 경쟁도 센 리그 |
| LEC | −30 | 1.1 | 0.9 | 주전 잡기 쉽고 명성은 덜 오름 |
| LCS | −60 | 1.2 | 0.8 | 상금·월급은 좋지만 약한 리그 |

(FPS 해외 3리그도 같은 방식으로 정한다.) 핵심은 **약한 리그로 가면 우승은 쉬워도 명성·월드 대비가 약해지고, 강한 리그는 반대**라는 것이다. 정확한 수치는 봇 측정 후 확정한다.

## 5. 해외 이적 시스템

### 5-1. 제안이 오는 시점

기존 3경로(시즌 결산·시즌 중간 제안·이적 요청)에 얹는다.

1. **해외 제안(`kind: 'overseas'`)을 시즌 결산 때 별도 카드로** 보여 준다(국내 이적 제안과 분리). 서로 **다른 해외 리그에서 한 팀씩 최대 3곳**, 거절 가능.
2. **이적 요청 시 "해외로 알아보기"** 선택지를 추가한다(시즌 결산 때 한정, 시즌당 한 번이라는 기존 규칙 공유). 성공 확률은 기존 공식(명성 비례) 그대로.
3. 시즌 중간 무작위 제안에는 해외를 섞지 않는다(너무 잦아져 정신없다).

### 5-2. 자격(초안)

프로 1부 소속 + 명성 ≥ 50 + 나이 ≤ 28 + 이번 시즌에 이미 이적하지 않았음. 해외 팀이 "관심을 보이는" 확률은 **내 실력치 R이 그 리그 평균 전력 이상일수록** 높다(실력이 안 되면 제안이 안 온다).

### 5-3. 제안 카드에 보여 줄 것 (피드백 8번)

리그명·지역, **리그 순위(국제전 성적 기준, §7)**, 그 리그에서의 팀 순위·전력·월급(리그 월급 배율 반영), 적응 난이도 표시("언어·문화 장벽: 큼/중간"), 이번 시즌 그 팀의 성적(기존 `seasonResultsOf` 재사용).

### 5-4. 이적 확정 때

- 계약 연출(`contractScene`)은 그대로 쓰되 문구만 "해외 이적 계약"으로 바꾼다.
- 새 팀·새 리그로 `GameState.league`, `team`이 바뀐다. 월급 협상·연봉 배율 초기화 규칙은 기존 이적과 같다.
- **계약금**(이적 보너스): 월급 몇 턴분을 일시금으로 지급 → 돈 소비처(피드백 7·12번) 문제와 자연스럽게 이어진다.
- **해외에서 국내로 복귀**도 같은 경로(해외 → 국내 제안)로 가능하다. 복귀는 적응 부담이 없다.

## 6. 해외 생활의 대가: 적응도

새 수치 `adaptation`(0~100) 하나로 단순하게 간다.

- 해외 이적 직후 30에서 시작하고 **시즌마다 +25**, 이벤트·시설로 더 오른다. 국내 소속이면 항상 100이다.
- **적응도가 낮으면**: 대회 전력 `−penalty × (100 − 적응도)/100`(초안 최대 −50), 컨디션 자연 회복 감소, 팀워크 증가량 감소. 첫 시즌에 약해졌다가 두 번째 시즌부터 제 실력이 나오는 곡선이다.
- **해외 전용 이벤트 8~10종**(`events.json`, `when`에 리그 조건 추가): 언어 장벽 속 첫 연습, 현지 팬 문화, 향수병, 한국인 동료·코치와의 만남, 시차·음식, 현지 방송 출연, 국내 팬의 응원 메시지 등. 선택지 일부가 적응도를 올리거나 멘탈을 깎는다.
- **시설 "통역·언어 코치"**(`facilities.json` 5번째): 적응도 상승 +속도를 올리는 돈 소비처. 구매 가격은 기존 시설 공식(단계 돈 규모 × 2.5^단계).
- 적응도는 **홈 화면 상태 줄**과 해외 이적 확인 팝업에 보여 준다(처음 해외를 가는 사람이 대가를 알고 결정하도록).

## 7. 리그 순위 집계와 월드 개최지

### 7-1. 리그 파워 랭킹 (피드백 8번 "한국 1위, 중국 2위…")

- 국제전(MSI·월드·마스터즈·챔피언스 등)의 **참가 팀 최종 순서(`RunRecord.order`)가 이미 전 팀 순위로 저장돼 있다.** 이걸 리그별로 합산(순위 → 포인트)하면 새 시뮬레이션 없이 시즌 리그 순위가 나온다.
- 시즌 결산 화면에 "이번 시즌 리그 순위 카드"를 추가하고, 제안 카드에는 직전 시즌 순위를 표시한다. 최근 3시즌 이동 평균으로 흔들림을 줄인다.
- 리그 `strength`(정적 수치)와 이 순위(결과)는 일치하지 않아도 된다(국제전 랜덤성이 있어 "올해는 LEC가 선전" 같은 이야기가 생긴다).

### 7-2. 월드 개최지 (도서관장 업적)

- 월드 개최지를 시즌마다 지역 순환으로 정한다(시드 고정 순서: 예 한국 → 중국 → 유럽 → 북미…). 개최지 리그 소속 팀에 홈 이점(초안 전력 +10)을 준다.
- **업적 "도서관장" = 내 소속 리그 지역이 아닌 곳에서 열린 월드에서 우승.** 월드 결과 카드·엔딩 기록에 개최지를 표시한다.
- 해외 업적 후보: **월드 와이드**(2개 이상 리그에서 시즌 우승), **용병왕**(3개 리그 소속 경험). 엔딩 추가는 후순위(§9 결정 7).

## 10. 구현 순서 (마일스톤, 각 단계마다 테스트·커밋)

1. **M1 리그 모델·데이터 이전**: `leagues.json`, 팀 풀 리그 단위 전환, 국제전 풀 재구성, 세이브 마이그레이션. **게임 동작은 그대로**(회귀 테스트가 그대로 통과해야 한다).
2. **M2 해외 일정·강도**: 템플릿 이름 치환, 리그 `strength`·월급 배율·명성 배율.
3. **M3 해외 이적 흐름**: 제안 생성·자격·카드 UI·확정·복귀·계약금.
4. **M4 적응**: 적응도·해외 이벤트·언어 코치 시설.
5. **M5 리그 순위·월드 개최지·업적**.
6. **M6 밸런스·문서**: 봇에 해외 옵션을 켜고 측정(해외 이적이 정답이 되지 않는지, 전체 난이도 회귀 기준 유지), `updates.json`·`CLAUDE.md`·노션 갱신.

## 11. 위험과 확인할 것

- **팀 이름 정확도**: 웹 검색으로 모은 값이라 틀릴 수 있다(기존 `intl` 24팀과 같은 문제). 사용자 확인 필요. **실존 선수 이름은 쓰지 않는다**(기존 규칙).
- **로고·권리**: 해외 팀이 늘면 로고 용량(지금 57개 약 436KB)과 권리 고지 범위가 늘어난다. 기존 결정("문제 제기 시 가상 이름으로 되돌림")을 그대로 따른다.
- **난이도 회귀**: 국제전 풀을 바꾸면 국제전 상대 전력 분포가 달라진다. M1에서는 평균 770·편차 35를 유지하는 것을 합격 기준으로 둔다.
- **봇의 한계**: 봇은 해외 이적의 "느낌"(적응 스트레스, 연봉 매력)을 평가하지 못한다. 수치는 직접 플레이로 확인한다.
- **규모**: 이번 변경은 `GameState`·세이브·팀 풀·일정·UI를 모두 건드리는 큰 작업이라 M1이 끝날 때까지 기존 기능의 회귀 여부를 가장 엄격히 본다.
