# 초반 커리어(16~21세) 개편안 — 초안, 승인 대기

테스트 플레이 피드백: "16세부터 21세까지 훈련만 계속하는 게 말이 안 된다. PC방 대회, 테스트 같은 고정 이벤트가 있어야 한다." 방향은 **고정 마일스톤 + 랜덤 이벤트**로 정했다.

## 1. 지금 문제

- 승급이 시즌 결산 때 `R ≥ 기준`이면 자동으로 일어난다. 플레이어는 훈련만 고르고, 승급은 결과 화면의 숫자일 뿐이다.
- 한 시즌 안에서 "내가 뭔가를 해냈다"는 순간이 없다. (대회는 결산 화면에서 한꺼번에 끝난다.)
- PC방 대회는 표준·정밀 모드에만 있고, 튜토리얼에는 없다.

## 2. 구조: 성적에 따라 갈라지는 루트 (필수 코스가 아니다)

고정된 건 "나이마다 어떤 기회의 문이 열린다"는 것뿐이고, 어느 문으로 들어가는지는 **성적과 선택**이 정한다. PC방 대회도 필수가 아니라 방구석 랭커 단계에서 매 시즌 열리는 기회이고, 못 하면 다시 도전한다.

```
16세 방구석 랭커 ──── PC방 대회 (시즌마다 열림, 최대 3번 도전)
        │
        ├─ 상위(4강 이상) ──► [정석 루트] 아카데미 입단 테스트 초대
        │                        ├ 합격 ─► 아카데미(팀 훈련 해금) ─► 연습생 계약 ─► 프로 트라이아웃 ─► 프로 2부
        │                        └ 불합격 ─► 1년 뒤 재도전 / 지역 대회로 우회
        │
        ├─ 중간(8강) ──► PC방 대회 재도전 + 랭크전·방송으로 명성 쌓기 ──┐
        │
        ├─ 부진(첫판 탈락) ─► 몇 번 더 도전 ───────────────────────────┤
        │                                                          ▼
        │                                              [우회 루트] 지역 아마추어 대회
        │                                                 ├ 상위 ─► 스카우트 제안 3팀(고르기) ─► 아마추어 팀
        │                                                 ├ 중간 ─► 아마추어 팀 공개 입단 테스트 ─► 합격 시 아마추어 팀
        │                                                 └ 부진 ─► 재도전 (나이 한계 있음)
        │
        └─ 명성이 먼저 오른 경우(방송·랭크전) ─► 성적과 무관하게 스카우트 이벤트가 끼어들 수 있음

아마추어 팀 ─► 프로 2부 입단 테스트(공개) 또는 스카우트 ─► 프로 2부 ─► 프로 1부 ─► 월드 (기존 구조)
정석 루트의 연습생 ─► 프로 트라이아웃(쉬운 편) ─► 프로 2부
```

**루트의 차이** (정석이 항상 정답이 되지 않도록 서로 장단이 있다)

| 루트 | 빠르기 | 장점 | 부담 |
|---|---|---|---|
| 정석 (PC방 상위 → 아카데미) | 프로 2부 도달 약 19~20세 | 팀 훈련 일찍 해금, 트라이아웃이 비교적 쉬움 | 아카데미 평가에서 탈락하면 한 해를 잃음. 입단 팀이 정해져 있어 선택폭이 좁음 |
| 우회 (지역 대회 → 스카우트/공개 테스트) | 프로 2부 도달 약 21~23세 | 스카우트에서 팀과 계약 조건을 고를 수 있음 | 늦다. 25세부터 반응속도·정확도가 떨어지므로 전성기가 짧아짐 |
| 늦깎이 (몇 번 탈락 후 복귀) | 더 늦음 | 복귀 이벤트, 극복 서사(엔딩 문구) | 나이 한계(예: 지역 대회 도전은 22세까지)를 넘으면 취미·스트리머 엔딩으로 기운다 |

**나이 한계와 시간 압박**: PC방 대회 도전 3번, 아카데미 재도전 1번, 지역 대회 도전 22세까지처럼 기회에 유한 횟수를 둬서 "아무 때나 다시 하면 된다"가 되지 않게 한다.

**랜덤 이벤트와의 연결**: 루트 상태(`GameState.path`)에 따라 이벤트 조건이 달라진다. 예) 아카데미 소속일 때만 "선배 연습생과의 스파링", 우회 루트에서만 "동네 PC방 사장님의 후원 제안", 부진한 시기의 "친구의 위로·가족의 걱정" 이벤트.

## 3. 테스트 시스템 (새로 만들 것)

- 합격 점수 = 항목별 능력치 가중합 + 무작위 편차(−) ± 준비 선택. 항목 구성과 기준 점수는 `data/tests.json`에 둔다.
- **준비 선택지**: 테스트 직전 턴에 "집중 준비(훈련 효율 ↑, 컨디션 ↓)", "컨디션 관리", "선배에게 조언" 중에서 고르면 점수 보정이 붙는다. 훈련 후보 3개와 같은 선택의 재미를 준다.
- 결과 화면은 항목별 점수 막대와 합격선을 보여 줘서, 부족했던 능력치가 눈에 보이게 한다. (킥루의 "잠재력은 상한" 설명처럼 이유가 읽히는 게 중요)
- 불합격해도 게임오버는 아니다. 재도전(다음 시즌), 하위 경로(지역 대회 → 아마추어), 또는 다른 팀의 늦은 제안 중 하나가 열린다.

## 4. kickru에서 가져올 것 (확인된 범위)

- 공개된 후보 중 한 명을 고르는 시작 → 지금의 뽑기와 합치기엔 이른 단계라 **보류**.
- 성장이 출전 시간·활약·건강·숨은 성장 특성에 영향받는다 → **팀 내 주전 경쟁**(출전 시간)은 3단계 이후 검토. 지금은 테스트·마일스톤이 우선.
- 은퇴 후 랭킹·베스트 일레븐 → 4단계(온라인 랭킹).
- kickru 가이드에는 훈련·이벤트·입단의 세부 규칙이 없다. 더 가져오려면 직접 플레이하며 알려 주셔야 한다.

## 5. 구현 단위 (승인 후, 커밋 단위)

1. `data/routes.json` + 엔진 `routes.ts`: 루트 그래프(노드·성적 조건·나이/횟수 한계)를 데이터로 두고, `GameState.path`·도전 횟수를 상태에 추가. 마이그레이션 포함.
2. PC방 대회를 루트의 첫 노드로 연결(튜토리얼 포함, 대회 구조는 `competitions.json` 재사용). 성적별 분기 구현.
3. `data/tests.json` + `tests.ts`: 테스트 판정과 준비 선택지. 결과 화면(UI).
4. 자동 승급을 루트 분기로 대체(정석·우회·늦깎이), 불합격과 나이 한계 처리, 루트별 이벤트 조건.
5. 난이도 리포트 재측정. 봇이 테스트 준비를 고르도록 수정하고 회귀 테스트 기준을 확인.
6. 기획서(`docs/design.md` §7·§8)와 노션 갱신.

## 6. 위험과 확인할 것

- 루트가 3갈래라 테스트 항목·합격선이 루트마다 달라진다. 데이터(JSON)로 두고 봇이 모든 루트를 지나가도록 해서 루트별 도달 시기와 월드 우승률이 크게 치우치지 않는지 리포트로 본다.
- 성장을 늦춘 지금은 R 450이 20세쯤이다. 마일스톤 나이(19세 아마추어 테스트)와 합격선을 같이 맞춰야 한다.
- 튜토리얼은 시즌당 2턴뿐이라 "준비 턴"을 넣기 어렵다. 튜토리얼은 준비 선택을 시즌 결산 화면 안에 포함하는 안이 필요하다.
- 불합격이 너무 잦으면 재미가 없다. 숙련 플레이 합격률 85~95%, 단순 플레이 40~60%를 첫 목표로 제안한다.
