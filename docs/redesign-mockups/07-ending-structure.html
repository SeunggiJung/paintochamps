지금은 그림·문구 → 업적 카드 여러 장 → 경력 → 요약 → 시즌별 기록이 한 열로 쭉 이어져요. 같은 내용을 두 가지 방식으로 나눠 봤어요. 테마 A(밝은 카드) 기준이고, 도트 그림은 지금 것을 그대로 써요(여기선 자리표시).

안 1. 단계로 넘기기 — 킥루의 점 단계처럼, 한 장씩 "다음"

엔딩은 이야기의 마무리라서 결말 → 업적 → 기록 순으로 한 장씩 넘겨요. 폭죽은 첫 장에서만 터져요. 단계마다 높이가 화면 한 장 안에 들어와요.
